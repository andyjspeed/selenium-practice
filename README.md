# Selenium Practice

Different tests created while learning Python-Selenium using the-internt.herokuapp.com

## Tools
- Python 3.14.3
- Selenium 4.41.0
- Firefox + GeckoDriver

## How to Run
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`
3. Run a test: `python tests/test_login.py`

## What's Being Tested
- Negative logins (invalid credentials)
- Login and then logout
- Waiting for a loading bar
